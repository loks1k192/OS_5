# OS_5

Репозиторий содержит материалы лабораторной работы №5 по предмету "Операционные системы"
Трассировка и анализ системных вызовов (результаты strace) и сопровождающую документацию.

Содержание репозитория
- strace_txt.txt — вывод strace (результат трассировки исполняемого файла)
- doc/ — заметки, отчёт и пояснения по лабораторной работе

Назначение
- Просмотреть и проанализировать последовательность системных вызовов, взаимодействие с файловой системой и сетевыми ресурсами.
- Использовать материалы для отчёта и воспроизведения эксперимента.

Как воспроизвести (Linux)
1. Собрать/получить исполняемый файл программы (название и инструкции в doc/).
2. Запустить трассировку:
   strace -f -o strace_output.txt ./your_program [args]
3. Сравнить/проанализировать полученный strace_output.txt с strace_txt.txt в репозитории.

Альтернатива для Windows
- Использовать Process Monitor (Procmon) из Sysinternals для захвата событий и экспорта логов.
